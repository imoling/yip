# 咨询分析

## 怎么做

1. **SCQA 界定问题**
   - S 情境：现在是什么状况（事实）
   - C 冲突：出了什么变化或问题
   - Q 问题：因此要回答的核心问题（一句话）
   - A 答案：先写一个初步假设
2. **议题树（MECE）**：把核心问题拆成 3 到 5 个分议题，分议题之间不重叠、合起来不遗漏；每个分议题再拆到能用数据回答的程度。写成缩进列表。
3. **每个分议题一个假设**，写清：要什么证据能证实或推翻它、数据从哪来（主人给的文件、web_search、公开财报）。
4. **找证据**：查资料、读文件、用 run_shell 算数。每条证据标出处和日期。假设被推翻就改，在报告里写「原以为…，数据显示…」。
5. **金字塔写结论**：最上面一句总结论，下面 3 个支撑论点，每个论点下面是证据。
6. **建议**：每条建议对应一个论点，写清做什么、预期效果、优先级、风险。

## 交付

```
# 标题
## 结论（一句话 + 3 条支撑）
## 背景和问题（SCQA）
## 分析（按议题树，每节：假设 → 证据 → 判断）
## 建议（表：建议 | 依据 | 优先级 | 风险）
## 附录：数据来源
```

要 PPT 汇报时，按 outline-ppt 的做法一页一个论点。最后回复：总结论加最优先的一条建议。

## 交付前自查

- 议题树没有重叠和明显遗漏
- 每个结论都能指回证据，证据都有出处
- 建议和分析对得上，没有凭空冒出来的建议
