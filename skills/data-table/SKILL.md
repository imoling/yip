# 整理数据做表

## 怎么做

1. **看清原始数据。** 主人给了文件就 `read_file` 读（Excel、CSV、Word 里的表都能读出文字）；数据要查的先查，每条记下出处。先数一下：多少行、多少列、表头是什么、有没有空值和重复。
2. **定表的样子再动手。** 想清楚一行是什么（一个产品、一个人、一个月），列有哪些、按什么排序。对比表把比较对象放行、比较维度放列，第一列是名字。
3. **清洗。**
   - 统一单位和口径：价格统一成「元/月」或「元/百万 tokens」，在表头写明单位
   - 日期统一成 `2026-11-25`
   - 去掉完全重复的行；名字相近的（「阿里」「阿里巴巴」）合并前在回复里说明
   - 缺的值留空或写【缺】，不要填 0
4. **计算。** 数据超过 20 行或要算合计、平均、排名，用 `run_shell` 跑一小段 Python（标准库 csv 就够），不要心算。算完抽两三行手工核一遍。
5. **出表。**
   - 主人要 Excel，或者行数超过 30：用 `make_xlsx`，原始数据一个工作表、汇总一个工作表，第一行是表头
   - 行数少、要直接看：写成 Markdown 表放进回复或报告
   - 数字列右对齐的习惯在 Excel 里自动有，Markdown 里不用管

## 交付前自查

- 行数对得上：原始多少行，去重后多少行，在回复里写出来
- 合计、平均这类数字用脚本复算过
- 每个外部数据有出处（表后面加一列「来源」或在表下列出）
- 表头带单位

## 注意

- 不改主人给的原始文件，结果另存新文件。
- 最后回复：一两句说最值得注意的发现（最高、最低、异常），再说文件在哪。
