# 文件夹盘点整理

## 怎么做

1. **只读盘点。** 用 run_shell 跑 Python 扫描主人指定的文件夹（只读）：路径、文件名、类型、大小、修改时间、内容哈希（大于 200 MB 的只取前 1 MB 算）。跳过 `.git`、`node_modules`、隐藏文件。结果存成 `盘点/清单.csv`。
2. **出发现：**
   - 重复：哈希相同的分组列出，标出建议保留哪个（路径最规范、时间最新的）
   - 疑似重复：文件名去掉「副本」「(1)」「final」「v2」后相同的
   - 空文件、0 字节、损坏的（Office 打不开的）
   - 大文件 Top 20
   - 长期没动的（超过一年）
3. **分类建议**：按「项目 / 主题 → 类型 → 年份」给一个目标目录结构，每个文件对应一个建议位置。拿不准的单列「待主人判断」。
4. **整理方案**写成表格和一个脚本：
   - `盘点/整理方案.xlsx`（make_xlsx）：原路径 | 建议动作（移动 / 重命名 / 删除重复 / 保留）| 目标路径 | 理由
   - `盘点/执行整理.sh`：只放 `mkdir -p` 和 `mv`，不放 `rm`；删除重复改成移到 `待删除/` 文件夹
5. **不要自己执行脚本**，交给主人看过再说。

## 交付

最后回复：一共多少文件、多大；重复多少组、能省多少空间；方案和脚本在哪。

## 注意

- 主人没授权的文件夹不碰；工作文件夹以外的只读
- 清单里不要把文件内容抄出来
