# 写公文通知

## 先定文种

| 要干什么 | 用 |
|---|---|
| 让下级或相关人员知道、照办 | 通知 |
| 向上级要批准、要支持 | 请示（一文一事，结尾「妥否，请批示」） |
| 向上级汇报工作，不要求批复 | 报告 |
| 平级或不相隶属单位之间商洽 | 函 |
| 记录会议议定事项 | 会议纪要 |

请示和报告不能混用；主人说「打个报告申请经费」，要写成请示，并在回复里说一句为什么。

## 通知的结构

1. **标题**：发文机关 + 关于 + 事由 + 的通知，例：「关于召开 2026 年度工作总结会的通知」。
2. **主送机关**：顶格，后加全角冒号，例：「各党支部、各部门：」。
3. **开头**：一句话交代依据或目的，以「现将有关事项通知如下：」收。
4. **正文**：按「一、」「（一）」「1.」「（1）」四级编号。会议通知必须有：时间（几月几日星期几 几点）、地点、参会人员、议程、有关要求（材料、请假、着装）、联系人和电话。
5. **落款**：发文机关和日期靠右，日期用阿拉伯数字「2026 年 11 月 25 日」。

## 生成

用 `make_docx`：`title` 放标题，`blocks` 依次放主送机关（`p`）、正文段落（`p`）、各级小标题（`h2` / `h3`）、议程表（`table`）、落款和日期（`right`）。文件名用标题。

## 交付前自查

- 时间、地点、人员齐全，星期几和日期对得上（今天的日期在系统提示里，用它推算）
- 编号层级没有跳级，标点全角
- 【待定】最多两三处，只留给真要主人定的：会议室、联系人和电话、具体名单；其他写成能直接用的通用说法，不编人名和数字
  - 参会人员写范围：「全体正式代表」「列席人员按有关规定通知」
  - 主人没说单位时，落款写部门通用落款「党委办公室」，不要写「中共【待定】委员会」
  - 议程按惯例写：听取和审议工作报告、选举等
- 语气庄重简洁，不用「小伙伴」「赋能」这类词

## 注意

- 主人给了单位名称、领导姓名就照抄，一个字都别改。
- 最后回复：一句话说清文种和要点，再列出要主人补的【待定】项。
