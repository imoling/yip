# 调研访谈纪要

和会议纪要的区别：会议纪要记「定了什么」，调研纪要记「听到了什么、说明了什么」。

## 怎么做

1. 拿到文字（录音转写同 meeting-notes 第 1 步）。
2. **基本信息**：调研主题、时间、地点、形式（走访 / 座谈 / 一对一访谈 / 电话）、受访者（单位、角色；要脱敏就写「某省公司信息部负责人」）、访谈人。
3. **按主题归纳，不按问答顺序。** 每个主题写：
   - 发现：一句话结论
   - 证据：1 到 3 句受访者原话，用引号，标是谁说的
   - 程度：几个人都提到 / 只有一人提到
4. **单列三块**：痛点和需求（按提到的频次排）、意外发现（和预想不一样的）、没问到或要再核实的。
5. **下一步**：要补访谁、要查什么资料、要给谁同步。

## 交付

- Markdown 为主；多场访谈时另做一张汇总表：主题 × 受访者，格子里写态度（支持 / 反对 / 未提及）。
- 最后回复：最重要的 3 个发现，各一句话。

## 交付前自查

- 原话是原话，没被改写成书面语
- 观点和事实分开写，推测要标「推测」
- 敏感信息（手机号、身份证、内部账号）删掉或脱敏
