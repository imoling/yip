# 周报月报和总结

## 先问清（缺了就按默认值，并在回复里说明）

- 写给谁：直属领导（默认）/ 管理层 / 全员
- 周期：本周 / 本月 / 本季度 / 全年
- 素材：主人给的流水账、日报、数据表、上期报告。上期报告有的话，一定拿来对比

## 结构

```
# 标题（团队或项目 + 周期）

## 一句话结论
这期最重要的一件事，带数字（「新签 3 家，完成季度目标 75%」）

## 关键数据
| 指标 | 本期 | 上期 | 变化 | 目标完成 |

## 主要进展
按重要性排 3 到 5 条，每条：做了什么 → 结果 → 意义

## 问题和风险
每条：问题 → 影响 → 打算怎么办 → 需要谁支持

## 下期计划
3 到 5 条，可核对（谁、什么、何时）
```

年度总结、述职再加：亮点案例（1 到 2 个讲具体）、能力和不足、明年目标。

## 写法

- 先结论后过程；不写「本周主要做了以下工作」这种开头
- 每条进展要有结果或数字，没有结果的合并成一句「推进中」
- 问题要配方案，不只诉苦
- 数字只用素材里有的，算出来的（增长率、完成率）用 run_shell 算，写清口径
- 周报 1 页内，月报 2 页内

## 交付

默认 Markdown；要 Word 用 make_docx，要 PPT 汇报用 outline-ppt 的做法。最后回复给出一句话结论和最大的一个风险。

## 交付前自查

- 本期和上期的数字口径一致
- 每个问题都有下一步
- 没有素材里没有的成绩
