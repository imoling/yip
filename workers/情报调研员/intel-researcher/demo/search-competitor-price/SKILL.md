# 检索竞品报价

## 怎么做

1. web_search 搜各家「官网 定价 / pricing / 价格说明」，优先官网和官方文档
2. web_fetch 打开定价页原文，按版本（个人 / 企业 / 私有化）和计费方式记下价格、单位、币种、生效日期
3. 各家口径不一致时原样记下，别自己换算，除非要求里写了要换算

## 交付

- 用 write_file 把结果写成 Markdown，放在这件事的文件夹里，文件名用中文说清是什么
- 每条事实带出处（网址或文件名）和日期；查不到的写【待补充】，不编数字

## 离线演示

没配模型时系统自动运行 scripts/main.py 返回演示数据；配了模型时不要运行它。
